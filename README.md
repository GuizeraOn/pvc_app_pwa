# Visión Clara PWA 👁️✨

**Visión Clara** is a premium Progressive Web Application designed to help users improve their ocular health through daily routines, guided exercises, and progress tracking.

Built with a focus on senior accessibility and a premium mobile-first user experience.

## ✨ Key Features

- **Guided Protocols**: Step-by-step routines for eye wellness.
- **Daily Tracker**: Motivation and consistency through visual rewards.
- **Library of Resources**: Deep dive into vision health education.
- **PWA Ready**: Install on your home screen for a native-like experience.
- **High Accessibility**: Optimized typography and high-contrast modes for seniors.

## 🚀 Tech Stack

- **React 18** + **Vite**
- **TailwindCSS 4** (Newest version)
- **Framer Motion** for smooth layout transitions.
- **Vite PWA Plugin** for offline support and installation.
- **Lucide React** for premium iconography.

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/GuizeraOn/pvc_app_pwa.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

### Building for Production

```bash
npm run build
```
The build artifacts will be in the `dist/` directory, ready for deployment to any static hosting (Vercel, Netlify, etc.).

## 📱 Mobile Installation

This app is a PWA. To install it:
1. **iOS**: Open in Safari → Tap 'Share' → 'Add to Home Screen'.
2. **Android**: Open in Chrome → Tap Three Dots → 'Install App'.
